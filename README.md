# Солнцезащитная плёнка с молекулярным накоплением солнечной энергии
## Трёхдневное задание по генеративному молекулярному дизайну (Computational PoC)

### 1. Постановка задачи и химическая концепция
Проект решает фундаментальную проблему генеративного молекулярного дизайна в условиях **непересекающейся многокритериальной разметки**:
$$D_A = \{(x_i, y_i^A)\}_{i=1}^{N_A}, \quad D_B = \{(x_j, y_j^B)\}_{j=1}^{N_B}, \quad \{x_i\} \cap \{x_j\} = \emptyset$$

* **Домен A (MOST)**: Фотопереключатели молекулярного накопления солнечной энергии (системы *NBD–QC* и азобензолы):
  * Длина волны изомеризации $\lambda_{max}^{(A)} \in [310, 420]\text{ нм}$;
  * Запас энергии изомеризации $\Delta H_{storage} \ge 40\text{ кДж/моль}$ ($> 0.3\text{ МДж/кг}$).
* **Домен B (UV / Кожа)**: Органические солнцезащитные фильтры и кожная безопасность (CosIng Annex VI, HuskinDB):
  * Поглощение в длинноволновом диапазоне $\lambda_{max}^{(B)} \ge 330\text{ нм}$ (критерий broad-spectrum $\lambda_c \ge 370\text{ нм}$);
  * Низкая проницаемость через кожу $\log K_p \le -2.5\text{ см/ч}$ (удержание в плёнке на роговом слое без системной абсорбции);
  * Синтетическая доступность: $SA\text{ score} \le 4.5$.
* **Химическая концепция (Вариант А)**: Единая гибридная молекула-фотопереключатель (бициклический остов норборнадиена с донорно-акцепторными хромофорными заместителями для батохромного сдвига в UVA-диапазон).

### 2. Структура проекта
```text
most_uv_molecular_design/
├── data/
│   ├── raw/                  # Сырые данные: M01 (photoswitches.csv), NBD/QC, UV-фильтры
│   └── processed/            # Канонизированные сплиты Train / Val / Test для D_A и D_B
├── models/                   # Обученные суррогатные оценщики A и B, независимые оракулы, AD-база
├── results/
│   ├── generated_b0.csv      # Таблица 1000 кандидатов базовой стратегии B0
│   ├── experiment_log.csv    # Журнал экспериментов со всеми бенчмарк-метриками
│   └── day1_summary.json     # Сводка результатов Дня 1 в формате JSON
├── src/
│   ├── __init__.py
│   ├── config.py             # Пороги свойств, гиперпараметры, random seeds
│   ├── data_loader.py        # Загрузка M01, сборка D_A и D_B
│   ├── preprocessing.py      # Curation, десолификация, проверка непересекаемости, Scaffold Split
│   ├── evaluators.py         # Обучение суррогатных моделей, оракулов и расчет Applicability Domain
│   ├── baseline_b0.py        # Базовая генеративная стратегия B0 (стохастический мутатор графов)
│   └── metrics.py            # Validity, Uniqueness, Novelty, Diversity, SA, Potts-Guy LogKp
├── run_day1.py               # ЕДИНАЯ КОМАНДА ЗАПУСКА ДНЯ 1
├── requirements.txt          # Зависимости проекта
└── README.md                 # Документация проекта
```

### 4. Результаты Дня 1 (Базовая стратегия B0)
* **Размер выборки D_A (MOST)**: 336 train, 42 val, 43 test.
* **Размер выборки D_B (UV/Skin)**: 38 train, 3 val, 7 test.
* **Проверка непересекаемости**: Строго подтверждена ($D_A \cap D_B = \emptyset$, 0 общих структур).
* **Метрики генерации базовой стратегии B0 ($N = 1000$)**:
  * **Validity**: **100.0%** (все 1000 структур валидны по правилам валентности RDKit).
  * **Uniqueness**: **100.0%** (1000 уникальных молекулярных структур).
  * **Novelty**: **99.4%** (структуры не содержатся в обучающих датасетах).
  * **Diversity**: **0.8687** (высокое разнообразие по расстоянию Танимото).
  * **Mean SA Score**: **5.20** (умеренная синтетическая сложность случайных мутаций).
  * **Joint Success Rate (JSR)**: **1.40%** (доля кандидатов, одновременно проходящих ограничения по фотохимии $\Omega_A$, УФ-защите $\Omega_B$ и области надежности Applicability Domain).

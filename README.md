# Солнцезащитная плёнка с молекулярным накоплением солнечной энергии
## Трёхдневное задание по генеративному молекулярному дизайну (Computational PoC)

### 1. Постановка задачи и химическая концепция
Проект решает фундаментальную проблему генеративного молекулярного дизайна в условиях **непересекающейся многокритериальной разметки**:

$$
D_A = \left\{ (x_i, y_i^A) \right\}_{i=1}^{N_A}, \quad D_B = \left\{ (x_j, y_j^B) \right\}_{j=1}^{N_B}, \quad \{x_i\} \cap \{x_j\} = \emptyset
$$


* **Домен A (MOST)**: Экспериментальная база фотопереключателей (**The Photoswitch Dataset M01**, 391 молекула) + комбинаторная библиотека замещённых норборнадиенов NBD-QC (1 500 молекул) с физическим расчётом $\Delta H_{storage}$ в силовом поле RDKit 3D MMFF94 (итого 1 891 уникальная молекула):
  * **Критерий A1**: Длина волны фотопереключения $\lambda_{max}^{(A)} \in [310, 420]\text{ нм}$ (попадание в наземный солнечный спектр).
  * **Критерий A2**: Удельная ёмкость накопления тепла $\Delta H_{storage} \ge 40.0\text{ кДж/моль}$ (термодинамический выход реакции фотоизомеризации NBD $\to$ QC).
  * **Критерий A3**: Фотостационарное состояние $x_B^{PSS} \ge 60\%$ и кинетический барьер термической релаксации $\log_{10} k_{Z\to E} \le -3.0\text{ с}^{-1}$ ($t_{1/2} \ge 1\text{–}8\text{ ч}$ при температуре кожи ~32–35 °C).
  * **Критерий A4**: Синтетическая доступность: $SA\text{ score} \le 4.5$ (Ertl SA).
* **Домен B (UV / Кожа)**: Экспериментальная оптическая база **Deep4Chem (M11)** + разрешённые фильтры **EU CosIng Annex VI (U01)** (3 476 уникальных УФ-молекул $\le 400\text{ нм}$):
  * **Критерий B1**: Длинноволновое поглощение $\lambda_{max}^{(B)} \in [330, 400]\text{ нм}$ (критерий broad spectrum $\lambda_c \ge 370\text{ нм}$, FDA/ISO 24443).
  * **Критерий B2**: Высокая экранирующая способность: молярная экстинкция $\log_{10} \varepsilon \ge 4.0$ ($\varepsilon \ge 10\,000\text{ M}^{-1}\text{см}^{-1}$, закон Бугера–Ламберта $A = \varepsilon c l$).
  * **Критерий B3**: Кожная барьерная ретенция: $\log K_p \le -2.5\text{ см/ч}$ (удержание в роговом слое без проникновения в кровь по модели Поттса–Гая, OECD 428).
  * **Критерий B4**: Молекулярный размер и липофильность ($MW \in [250, 600]\text{ Да}$, $\log P \in [1.5, 5.5]$, правило 500 Дальтон, несмываемость себумом/потом).
* **Химическая концепция (Вариант А)**: Единая гибридная молекула-фотопереключатель (бициклический остов норборнадиена с донорно-акцепторными хромофорными заместителями для батохромного сдвига в UVA-диапазон).

### 2. Структура проекта
```text
most_uv_molecular_design/
├── data/
│   ├── sources/              # Исходные документированные базы данных
│   │   ├── group_A/          # M01 (photoswitches_M01.csv), nbd_derivatives_seeds.csv, README.md
│   │   └── group_B/          # M11 (deep4chem_M11.csv), U01 (cosing_annex_vi_U01.csv), README.md
│   ├── raw/                  # Скомпилированные датасеты D_A (1 891 мол.) и D_B (3 476 мол.)
│   └── processed/            # Канонизированные сплиты Train / Val / Test для D_A и D_B
├── models/                   # Обученные Evaluators (A_wl, A_dh, A_pss, A_k, B_wl, B_eps), оракулы, AD
├── results/
│   ├── generated_b0.csv      # Таблица 1000 кандидатов базовой стратегии B0 (все 8 критериев)
│   ├── experiment_log.csv    # Журнал экспериментов со всеми бенчмарк-метриками
│   └── day1_summary.json     # Сводка результатов Дня 1 в формате JSON
├── src/
│   ├── __init__.py
│   ├── config.py             # Пороги 4+4 критериев, пути к sources, random seed=42
│   ├── data_loader.py        # Инициализация датасетов напрямую из data/sources/
│   ├── preprocessing.py      # Curation, десолификация, проверка непересекаемости, Scaffold Split
│   ├── evaluators.py         # Обучение 8 оценщиков свойств, независимых оракулов и расчет AD
│   ├── baseline_b0.py        # Базовая генеративная стратегия B0 (стохастический мутатор графов)
│   └── metrics.py            # Validity, Uniqueness, Novelty, Diversity, Ertl SA, Potts-Guy LogKp
├── run_day1.py               # ЕДИНАЯ КОМАНДА ЗАПУСКА ДНЯ 1
├── requirements.txt          # Зависимости проекта
└── README.md                 # Документация проекта
```

### 4. Результаты Дня 1 (Базовая стратегия B0, 4+4 критерия)
* **Размер выборки D_A (MOST M01 + NBD-QC)**: 1 506 train, 188 val, 189 test (1 883 уникальных канонических молекулы).
* **Размер выборки D_B (UV M11 + CosIng)**: 2 780 train, 347 val, 349 test (3 476 уникальных канонических молекул).
* **Проверка непересекаемости**: Строго подтверждена ($D_A \cap D_B = \emptyset$, 0 общих структур).
* **Метрики генерации базовой стратегии B0 ($N = 1000$)**:
  * **Validity**: **100.0%**
  * **Uniqueness**: **100.0%**
  * **Novelty**: **99.5%**
  * **Diversity**: **0.8671**
  * **Mean SA Score**: **5.20**
  * **Pass Group A (все 4 критерия MOST)**: **22.80%**
  * **Pass Group B (все 4 критерия UV/Skin)**: **3.70%**
  * **Within Applicability Domain (надежная область AD)**: **34.30%**
  * **Joint Success Rate (JSR - ВСЕ 8 критериев одновременно)**: **0.20%**

*Низкий начальный JSR (0.20%) для случайного мутационного бейзлайна B0 наглядно отражает фундаментальную сложность задачи: нескоординированный поиск практически не попадает в узкую область совместного оптимума 8 физико-химических критериев. Это идеальный baseline для демонстрации преимуществ исследуемого метода M1 (направленной оптимизации) в Дни 2–3.*
